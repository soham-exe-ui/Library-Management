LIBRARY MANAGEMENT SYSTEM

This website follows the reference layout and workflow:
- Dashboard
- Add Book
- Display Books
- Search Book
- Issue Book
- Return Book
- Issued Books

HOW TO RUN
1. Extract the ZIP.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in a browser, or use VS Code Live Server.

FEATURES
- Add books with unique Book IDs
- Search by Book ID, title or author
- Issue and return books using Book ID and Student ID
- Automatic available-copy updates
- Dashboard counters and active issue register
- Responsive layout for desktop, tablet and mobile
- Data saved in browser LocalStorage

GITHUB PAGES
Upload index.html, style.css and script.js together into the same repository folder. Do not rename them unless you also update the file references in index.html.
